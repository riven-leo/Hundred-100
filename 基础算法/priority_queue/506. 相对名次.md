# 什么时候用pair，什么时候用哈希表
当你有两个信息必须一起移动、一起排序、一起保存时，用 pair
当你需要通过一个 key，频繁查询它对应的信息时，用哈希表。

# emplace_back和push_back的区别
前者是后者的内存优化版本
直接在vector里建立pair对象，而不会显式建立一个临时pair对象
m.emplace_back(-score[i], i); 
m.push_back(make_pair(-score[i], i));

# sort O(nlogn)
sort(m.begin(), m.end(), greater<pair<int, int>>())
默认升序改成降序，时间复杂度不变
