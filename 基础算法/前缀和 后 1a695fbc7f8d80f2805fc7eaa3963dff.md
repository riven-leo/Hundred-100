# 前缀和 后

Status: Not started

前缀和是指数组中从起始位置到某个位置的元素之和，后缀和是指数组中从某个位置到结尾位置的元素之和。

前缀和和后缀和通常用于优化区间求和问题，通过预处理数组，能够在常数时间内计算任意区间的和，从而提高效率。

前缀和和后缀和在解决多种问题时都非常有用，特别是在需要频繁查询数组区间和的场景，常见的用途包括：

1. **区间和查询**：通过预计算前缀和或后缀和，可以在常数时间内求出任意区间的和，避免每次查询时都进行重复计算。
2. **动态规划优化**：在一些动态规划问题中，前缀和和后缀和可以帮助快速计算状态转移的值，减少时间复杂度。
3. **差分数组**：在处理区间修改问题时，可以通过前缀和来实现高效的更新操作，避免重复遍历更新区间。
4. **算法竞赛**：在各种算法题目中，前缀和和后缀和经常用于加速求解过程，特别是在涉及大数据量的情况下。

尤其是在需要多次查询和更新数组的场景下。

板子：

```cpp
储存和输入
const int N = 10;
int prefix[N+1], suffix[N+1];
int s[N];//注意放缀和的数组要比数组大1格

**核心代码**
    for (int i = 0; i < n; i++) {
        prefix[i+1] = prefix[i] + s[i];
    }
    for (int i = n-1; i >= 0; i--) {
        suffix[i] = suffix[i+1] + s[i];
    }
**输出** 
    int l, r; cin >> l >> r;//后缀和可以从0开始也可以从1开始，随机应变索引的变化
    cout << prefix[r] - prefix[l-1] << " " << suffix[l-1] - suffix[r];
```
