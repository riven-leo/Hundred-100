# 树（教科书）

[树的学习策略](%E6%A0%91/%E6%A0%91%E7%9A%84%E5%AD%A6%E4%B9%A0%E7%AD%96%E7%95%A5%201a395fbc7f8d800f996fcba1d1900601.md)

1. **树的基本定义**
    - 树的结构：树由节点和边组成，每个节点包含数据，节点之间通过边连接。
    - 根节点：树的起始节点，没有父节点。
    - 叶子节点：没有子节点的节点。
    - 父节点与子节点：父节点指向子节点，反之是子节点指向父节点。
    - 层次/深度：从根节点到某个节点的路径长度称为该节点的深度，根节点的深度为0，层次是相同深度的节点集合。
    - 子树：树中的任意节点及其所有后代构成的子结构。
2. **二叉树(binary tree)**
- **性质记忆口诀**：
    - **"满则对称美，完全左铺满，平衡限高差”**
    - **k层最多二的(k减一)次块**
    - **层数定边界，最高满树开**
    - **两度节点加一叶**
    - **满层填满最矮个，取整加一不会错**
- 分类+常见概念
    
    分类：  看图即可
    
    - 完美二叉树（prefect binary tree）（满二叉树）
        - 所有层的节点都被完全填满。在完美二叉树中，叶节点的度为0，其余所有节点的度都为2；若树的高度为h，则节点总数为$2^{h+1}−1$
    - **完全二叉树**：除了最后一层外，所有层都已满，且最后一层的节点都靠左排列。
    - <u>完满二叉树（full binary tree）</u>除了叶节点之外，其余所有节点都有两个子节点。
    - **平衡二叉树**（AVL树、红黑树等）：任意节点的左子树和右子树的高度之差的绝对值不超过 1 。确保树的高度保持在对数级别，以提高查询效率。
    
    - <u>根节点（root node）</u>：位于二叉树顶层的节点，没有父节点。
    - <u>叶节点（leaf node）</u>：没有子节点的节点，其两个指针均指向 `None` 。
    - <u>边（edge）</u>：连接两个节点的线段，即节点引用（指针）。
    
    - 节点的<u>度（degree）</u>：节点的子节点的数量。在二叉树中，度的取值范围是 0、1、2 。
    - 二叉树的<u>高度（height）</u>：从最远叶节点到根节点所经过的边的数量
    
    - 节点所在的<u>层（level）</u>：从顶至底递增，根节点所在层为 1 ，层次是相同深度的节点集合。
    - 节点的<u>深度（depth）</u>：从顶至底递增，从根节点到该节点所经过的边的数量，根节点的深度为0
    
    - 节点的<u>高度（height）</u>：从底至顶，从该节点到树中最深叶子节点的路径长度。
        - **叶子节点的高度**是 0，因为它没有子节点，没有进一步的路径可走。
        - **非叶子节点的高度**是其子节点的最大高度 + 1。也就是说，节点的高度是其子树的最大高度，再加上 1。
    
    ```
        1           max(1, 0) + 1 = 2
       / \
      2   3           max(高度(4), 高度(5)) + 1 = max(0, 0) + 1 = 1
     / \
    4   5
    
    **Tip：**
    
    请注意，我们通常将“高度”和“深度”定义为“经过的边的数量”，但有些题目或教材可能会将其定义为“经过的节点的数量”。在这种情况下，高度和深度都需要加 1 。
    ```

class tnode {

    int val;
    tnode* ls;

        ls = nullptr;

int main(){

    tnode* n1 = new tnode(1);
    tnode* n2 = new tnode(2);

    tnode* n4 = new tnode(4);

    n1->rs = n3;
    n2->ls = n4;
    n2->rs = n5;
    //插入新节点
    tnode* p = new tnode(0);
    n1->ls = p;
    p->rs = n2;
    //删除新节点
    n1->ls = n2;
    delete p;

    return 0;
}

这里需要手动分配空间的原因是你在使用的是指针（`TreeNode*`）来表示树中的节点，而在 C++ 中，指针类型的变量并不会自动分配内存空间。简单地声明一个指针变量，比如 `TreeNode* n1;`，仅仅是定义了一个指向 `TreeNode` 类型的指针，并没有实际分配内存空间来存储一个 `TreeNode` 对象。如果你想在内存中创建一个真正的 `TreeNode` 实例，必须手动使用 `new` 关键字来进行动态内存分配。

因此，`new TreeNode(1)` 语句的作用是创建一个新的 `TreeNode` 对象，并返回一个指向该对象的指针，然后将这个指针赋值给 `n1`，从而使 `n1` 指向这个新创建的 `TreeNode` 对象。同理，对于其他节点的创建，都是通过 `new` 关键字来分配内存。

而如果直接声明变量（如 `TreeNode n1;`），那么变量 `n1` 会在栈上分配内存，生命周期和作用域都受到限制，且无法通过指针建立父子节点之间的关系，因此不适合用来表示需要动态分配内存的树结构。

# 树的遍历

1. ***层序遍历***

从顶部到底部逐层遍历二叉树，并在每一层按照从左到右的顺序访问节点。

层序遍历本质上属于<u>广度优先遍历（breadth-first traversal）</u>，也称<u>广度优先搜索（breadth-first search, BFS）</u>，它体现了一种“一圈一圈向外扩展”的逐层遍历方式。

```cpp
//BFS层序遍历
vector<int> levelOrder(tnode* root) {
    queue<tnode*> q;
    q.push(root);
    vector<int> ans;
    while(!q.empty()) {
        tnode* tmp = q.front();
        ans.push_back(tmp->val);
        q.pop();
        if (tmp->ls != nullptr)
            q.push(tmp->ls);
        if (tmp->rs != nullptr)
            q.push(tmp->rs);
    }
    return ans;
}
```

- **复杂度分析**
On，访问了n个数
1. ***前序、中序、后序遍历***
- 前序遍历是根节点在最前面，然后是左子树和右子树；中序遍历是左子树、根节点、右子树；后序遍历则是左右子树在前，根节点在最后
    - 可以和横着想树
- **对树进行深度优先遍历就像是绕着整棵二叉树的外围“走”一圈**，在每个节点都会遇到三个位置，分别对应前序遍历、中序遍历和后序遍历。
- 递归过程可分为“递”和“归”两个逆向的部分。
1. “递”表示开启新方法，程序在此过程中访问下一个节点。
2. “归”表示函数返回，代表当前节点已经访问完毕。

![image.png](%E6%A0%91/image.png)

```cpp
//DFS前中后序遍历
void preOrder(tnode* root) {
    if (root == nullptr) return ;
    //根左右
    ans.push_back(root->val);
    preOrder(root->ls);
    preOrder(root->rs);
}
void inOrder(tnode* root) {
    if (root == nullptr) return ;
    //左根右
    inOrder(root->ls);
    ans.push_back(root->val);
    inOrder(root->rs);
}
void postOrder(tnode* root) {
    if (root == nullptr) return ;
    //左右根
    postOrder(root->ls);
    postOrder(root->rs);
    ans.push_back(root->val);  
}
```

- **复杂度分析**
On，访问了n个数
- ***部分知二求一***
    1. **已知前序+中序，或后序+中序**
        
        可以唯一确定二叉树的结构，进而推导出第三种遍历。
        
        - **前序+中序**：前序确定根节点，中序划分左右子树，递归构造。
        - **后序+中序**：后序确定根节点，中序划分左右子树，递归构造。
    2. **已知前序+后序**
        
        无法唯一确定二叉树的结构，因此无法推导出中序或其他遍历。
        
        - 原因：当存在单子树（仅左或仅右）时，前序和后序无法区分左右，导致多解。
        - 例：前序 `[1, 2]` + 后序 `[2, 1]` 可能对应两种结构：根1的左子为2，或根1的右子为2。
    
    **结论**：
    
    - **必须包含中序遍历**才能知二求一。
    - 仅前序+后序的组合无法确定唯一二叉树。

# 树和递归

是的，你可以说这种定义在某种程度上类似于“套娃”，但其实它是二叉树节点的常见设计模式。在这里，`Node` 类包含了两个指针（`left` 和 `right`），它们分别指向当前节点的左子节点和右子节点。每个节点本身是一个对象，但它们又通过指针相互连接，形成了一种递归结构。

### 递归结构的解释：

1. **节点的定义**：`Node` 类的每个实例都包含一个 `data`（数据域），以及指向其他 `Node` 对象的指针——`left` 和 `right`。这就意味着每个节点可以包含两个子节点，每个子节点也是一个 `Node` 类型的对象。
2. **递归性**：这种设计的关键是递归性。`Node` 本身定义了两个指向 `Node` 类型的指针，这使得每个节点可以看作是一个小型的子树。每个子树本质上又是一个 `Node` 类型的结构（即每个子节点本身也可能有左子树和右子树），这种结构可以通过递归来表达。

### 为什么叫“套娃”？

- 可以将这种结构类比为“套娃”是因为每个节点（`Node`）内部包含了对子节点（`left` 和 `right`）的引用，而每个子节点又有自己的子节点，形成了一种递归嵌套的关系。就像套娃一样，每个节点的结构里面可能再有相同类型的子结构。

### 举个例子：

假设有如下的二叉树：

```
        1
       / \
      2   3
     / \
    4   5

```

它的对应 `Node` 结构可以通过以下方式表示：

```cpp
Node* root = new Node(1);
root->left = new Node(2);
root->right = new Node(3);
root->left->left = new Node(4);
root->left->right = new Node(5);

```

这里：

- `root` 是一个 `Node` 类型的对象，它的 `data` 是 `1`，它有左右子节点，分别指向值为 `2` 和 `3` 的节点。
- `root->left` 是值为 `2` 的节点，它又有左右子节点，分别指向值为 `4` 和 `5` 的节点。

这个结构的每一个节点都递归地包含两个指向其他节点的指针。

### 递归与套娃的关系：

- **递归**：每个节点（`Node`）本身就包含了指向其他节点（`left` 和 `right`）的指针，这种递归的结构使得树的操作（如遍历、插入、删除等）可以通过递归来实现。
- **套娃**：类似“套娃”的概念是指每个节点内部嵌套了对其他节点的引用，形成了一种层层递进、嵌套的关系，像是一个自包含的结构。

### 总结：

- 定义二叉树节点时，`Node` 类内部通过指针指向其他 `Node` 对象，这种设计是 **递归结构**，并且每个节点对象都可以包含其他节点对象的引用，从而形成一棵树的结构。
- 这种设计模式不仅高效，而且非常自然，因为树结构本身就是递归定义的，所以这也能让你通过递归函数方便地操作树。

所以，虽然这种结构可能让人联想到“套娃”，但它本质上是递归结构的一部分，是树形数据结构的标准实现方式。

你提到的 `Node(int value)` 其实是 **构造函数**，而不是内置函数。在 C++ 中，构造函数是类的一种特殊成员函数，它在创建类对象时被自动调用，用来初始化类的成员变量。构造函数的特点是：

- **没有返回类型**：构造函数与普通函数不同，它不需要指定返回类型。即使你在函数中执行了一些操作或返回了一些结果，构造函数本身也不需要返回值，因为它的目的是初始化对象。
- **名字与类名相同**：构造函数的名字必须与类名相同，在这个例子中，类名是 `Node`，所以构造函数的名字也是 `Node`。

### 构造函数的定义

```cpp
class Node {
public:
    int data;
    Node* left;
    Node* right;

    // 这是构造函数的定义
    Node(int value) {
        data = value;     // 用传入的值初始化数据
        left = nullptr;   // 初始化左子节点为空
        right = nullptr;  // 初始化右子节点为空
    }
};

```

### 解释

- **没有返回类型**：构造函数 **不需要** 返回类型，因此你不需要写 `void` 或任何类型（如 `int` 或 `float`）。构造函数的任务是创建并初始化对象，而不是计算并返回一个值。
- **与类名相同**：构造函数的名字必须与类名相同，这就是 `Node`（类名）和 `Node(int value)`（构造函数名）相同的原因。构造函数的目的是构建一个对象，所以它的名字必须与类名一致，这样编译器就知道它是用于创建该类的对象的特殊函数。

### 为什么不需要返回类型

构造函数的目的是 **初始化** 类的对象。当你创建一个对象时，构造函数会在幕后被自动调用，执行初始化的操作。如果你像普通函数一样指定返回类型（比如 `void`），它就会与构造函数的设计目的冲突。

举个例子，通常你会看到类似这样的代码：

```cpp
Node* node = new Node(10);  // 创建一个新的Node对象并通过构造函数初始化它

```

- 在这行代码中，`Node(10)` 是 **构造函数的调用**，它会被自动调用来创建并初始化 `Node` 对象。
- 构造函数内部并不返回值，它直接操作对象的状态（例如设置 `data`、`left` 和 `right`），这就是它的职责。

### 构造函数的作用

1. **初始化对象**：构造函数用于初始化新创建对象的成员变量。在你的 `Node` 构造函数中，`data` 被初始化为传入的 `value`，`left` 和 `right` 被初始化为 `nullptr`。
2. **自动调用**：当你创建 `Node` 类型的对象时，构造函数会自动执行，完成对象的初始化。这也是为什么你不需要显式地调用构造函数的原因。

### 总结

- **构造函数没有返回类型**，因为它的目的不是返回数据，而是初始化对象。
- 构造函数的 **名称必须与类名相同**，这是 C++ 语言的规定。
- 在创建对象时，构造函数会被自动调用，你不需要显式地调用它或者为其指定返回类型。
