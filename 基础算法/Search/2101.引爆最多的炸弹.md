int dfs(int x) 内部计数
它负责返回某个明确的信息，例如：
*子树节点数，最大深度，路径长度，连通块大小*

void dfs(int x) 外部计数
把答案存在外部变量里：
void dfs(int x) {
    vis[x] = 1;
    cnt++;
    for (int next : g[x])
        if (!vis[next]) 
            dfs(next);    
}

外层：
for (int i = 0; i < n; i++) {
    fill(vis.begin(), vis.end(), 0);

    int cnt = 0;
    dfs(i);

    ans = max(ans, cnt);
}

DFS 完成后，这个 cnt 就是当前起点的答案。


递归思维：
父问题不需要亲自统计整棵树，只需要让每个子问题返回自己的答案，再把它们组合起来。


**怎么理解vis数组？以及如何使用？**
DFS 在图中探索时，会动态构造出一棵 DFS 搜索树。vis 决定哪些边能进入这棵树。

**怎么理解int dfs(i)?**
dfs(x) 返回：
从 x 出发，本次 DFS 新访问到的节点数量
cnt += dfs(next);
因为每层函数返回自己的子树大小，子树访问了多少个新节点，就全部加到当前这棵树里。
