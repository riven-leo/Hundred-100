# 2101 引爆最多的炸弹

## 模型总结

int dfs(int x)

它负责返回某个明确的信息，例如：

*子树节点数，最大深度，路径长度，连通块大小*

这是一种很重要的递归思维：

父问题不需要亲自统计整棵树，只需要让每个子问题返回自己的答案，再把它们组合起来。

你以后写递归前，先强迫自己补全这句话：

*dfs(x) 表示……，dfs(x) 返回……*
