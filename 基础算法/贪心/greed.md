# 贪心

# 3219 切蛋糕的最小总开销II

输入/输出：输入蛋糕大小mn，开销数组hc[i],vc[j]/输出总开销

范围：long long->

## 概念

贪心——做出假设，然后进行正确性证明

最小生成树 Kruskal 的规则是：

将所有边按权值从小到大排序；如果一条边连接了两个不同连通块，就把它加入生成树，否则跳过。

## 思路

**从模糊的思路到具体操作的决策**

当题目要求安排若干操作的执行顺序，并且先做某个操作会改变后续操作成本时，先拿两个操作出来，比较 AB 与 BA。

分析每次切存在两种顺序，先水平后垂直则开销为hc[i]+2 *vc[j]，先垂直后水平则开销为vc[j]+2* hc[i]，因为每次操作蛋糕都被分为两个独立小蛋糕，为了总开销最小，需要从**贪心的角度**每次切应该从水平和垂直中最大的一个边开始切，这样另一个小的乘以2（题解存在争议）

## 伪代码

要存一个在切的过程中在下一次切之前行和列增加到了多少

long long h = 1, v = 1;

long long ans = 0;

sort hc[] and vc[]

while (!hc.empty() || !vc.empty())

if vc.empty || !hc.empty && hc.back > vc.back

ans += hc.back*h;
hc.pop_back;
v++;
else
ans += vc.back*v;
vc.pop_back;
h++;
return ans
