面对递归问题时，可以按照以下结构化思路逐步拆解，避免陷入无限循环的思维陷阱：

---

### *1. **先想「最小问题」——终止条件**

**核心问题**：递归的尽头是什么？

就像俄罗斯套娃拆到最小的那个时，必须停止。

- **例子**：计算阶乘 `n!`
    - 终止条件：当 `n=1` 时，直接返回 `1`（最小的套娃里是确定的答案）
- **错误示范**：忘记终止条件会导致无限递归（程序崩溃）

---

### *2. **拆解「当前问题」与「子问题」**

**核心问题**：如何把大问题变成更小的同类问题？

想象自己站在套娃的第N层，只需要关心「拆当前层」和「交给下一层」两件事。

- **例子**：斐波那契数列 `F(n) = F(n-1) + F(n-2)`
    - 当前问题：`F(n)`
    - 子问题：`F(n-1)` 和 `F(n-2)`（交给下一层套娃解决）
- **关键技巧**：不要深入递归细节，**假设子问题已经解决**（递归的信任飞跃）

---

### *3. **画递归树（可视化递归逻辑）**

**核心问题**：递归的调用关系如何展开？

用树状图模拟函数调用，避免大脑陷入递归黑洞。

- **例子**：计算 `3!` 的递归树：
    
    ```
    3! → 调用 2!
          ↓
          2! → 调用 1!
                ↓
                1! → 返回 1
    ```
    
- **作用**：直观看到递归的「分形结构」，发现重复计算（比如斐波那契的冗余分支）

---

### *4. **警惕递归陷阱**

**常见错误**：

- **堆栈溢出**：忘记终止条件或递归深度太大
- **重复计算**：同一子问题被多次计算（斐波那契典型问题）
    - **解法**：用「记忆化」（缓存结果）或改用迭代
- **过度递归**：某些问题递归不是最优解（比如链表反转）

---

### *5. **经典题型训练法**

从简单到复杂逐步练习，培养递归直觉：

1. **单向递归**：阶乘、斐波那契
2. **分治递归**：归并排序、快速排序（拆分子问题再合并）
3. **回溯递归**：全排列、迷宫问题（尝试→失败→回退）
4. **树形递归**：二叉树遍历、路径总和

---

### **递归思维口诀**

**"只信当前层，子问题当黑盒，尽头先想清"**

- 你只需处理当前层逻辑，相信递归能解决子问题
- 像老板分配任务：自己只做关键一步，剩下的交给下属（递归函数）

---

**例子实战**：反转链表（递归解法）

```python
def reverse_list(head):
    # 终止条件：空节点或最后一个节点
    if not head or not head.next:
        return head

    # 子问题：反转 head.next 之后的链表
    new_head = reverse_list(head.next)

    # 当前层逻辑：让下一个节点指向自己
    head.next.next = head
    head.next = None

    return new_head
```

**思考过程**：

1. 终止条件：链表为空或只剩一个节点时，无需反转
2. 子问题：`reverse_list(head.next)` 能正确反转剩余链表
3. 当前层：将 `head` 的下一个节点指向自己，再断开原有连接

---

通过这种结构化思维，递归会从「魔法」变成可掌控的工具。关键是：**先定义清楚问题边界，再信任递归解决子问题**。
