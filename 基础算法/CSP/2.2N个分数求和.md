1. 最大公约数gcd
    辗转相除法：
    数学前提：a和b的gcd等于b和a%b的gcd
    如果余数为0时， 此时的除数就是最大公约数
    1. 递推实现：
    auto gcd(auto a, auto b) {
        while (b != 0) {
            t = a % b;
            a = b;
            b = t;
        }
        return a;
    }
    2. 递归实现：
    auto gcd(auto a, auto b) {
        return b == 0 ? a : gcd(b, a % b);
    }
2. 最小公倍数lcm
return a * b / gcd(a, b);
usually, more correctly, return a / gcd(a, b) * b;
because type of a, b is long long;

a和b，辗转后，b做被除数，a除以b的余数即a % b做除数，两者相除，会得到新的余数
如果余数不为0，则此时的除数再做被除数，余数做除数，再相除
如果余数为0，则此时除数是ab的最大公约数，这个在数学上已证明过

现在考虑数字层面，ab可能都是负数，a可能> b可能< b
使用gcd函数时，保证较大的数给a，较小数给b
在函数内使用 if (a < 0) a = -a; if (b < 0) b = -b;处理负数

递归是在计算机科学出现后的近代，用来解决一些问题的工具，是由果溯因的后向思维，而递推是由因推果的前向思维，人类更易理解
果是递归出口
gcd(a, b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}
