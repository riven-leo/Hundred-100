# 栈（Stack）

栈是一种**线性数据结构**，具有后进先出（LIFO, Last In First Out）的特性。栈只允许在一端进行数据的插入和删除操作，这一端被称为**栈顶（Top）**。

- **栈的基本操作**
    1. **Push（入栈）/emplace构造生成：** 向栈顶添加一个元素。
    2. **Pop（出栈）：** 从栈顶移除并返回一个元素。
    3. **Peek/Top（取栈顶元素）：** 查看栈顶的元素，但不移除。
    4. **isEmpty（判断栈空）：** 检查栈是否为空。
    5. **isFull（判断栈满）：** 在固定大小的栈中检查是否已满。
- 栈的c实现
    
    **1. 基于数组的栈（C语言）**
    
    ```c
    #include <stdio.h>
    #include <stdlib.h>
    #include <stdbool.h>
    
    #define MAX_SIZE 100
    
    typedef struct {
        int data[MAX_SIZE];
        int top;  // 栈顶指针
    } Stack;
    
    // 初始化栈
    void initStack(Stack* stack) {
        stack->top = -1;
    }
    
    // 判断栈是否为空
    bool isEmpty(Stack* stack) {
        return stack->top == -1;
    }
    
    // 判断栈是否满
    bool isFull(Stack* stack) {
        return stack->top == MAX_SIZE - 1;
    }
    
    // 入栈
    void push(Stack* stack, int value) {
        if (isFull(stack)) {
            printf("Stack overflow\n");
            return;
        }
        stack->data[++stack->top] = value;
    }
    
    // 出栈
    int pop(Stack* stack) {
        if (isEmpty(stack)) {
            printf("Stack underflow\n");
            exit(EXIT_FAILURE);
        }
        return stack->data[stack->top--];
    }
    
    // 获取栈顶元素
    int peek(Stack* stack) {
        if (isEmpty(stack)) {
            printf("Stack is empty\n");
            exit(EXIT_FAILURE);
        }
        return stack->data[stack->top];
    }
    
    int main() {
        Stack stack;
        initStack(&stack);
        push(&stack, 10);
        push(&stack, 20);
        push(&stack, 30);
        printf("Top element: %d\n", peek(&stack));  // 输出 30
        printf("Popped element: %d\n", pop(&stack));  // 输出 30
        printf("Top element after pop: %d\n", peek(&stack));  // 输出 20
        return 0;
    }
    
    ```

    **2. 基于链表的栈（C语言）**
    
    ```c
    #include <stdio.h>
    #include <stdlib.h>
    #include <stdbool.h>
    
    // 定义节点
    typedef struct Node {
        int data;
        struct Node* next;
    } Node;
    
    // 定义栈
    typedef struct {
        Node* top;
    } Stack;
    
    // 初始化栈
    void initStack(Stack* stack) {
        stack->top = NULL;
    }
    
    // 判断栈是否为空
    bool isEmpty(Stack* stack) {
        return stack->top == NULL;
    }
    
    // 入栈
    void push(Stack* stack, int value) {
        Node* newNode = (Node*)malloc(sizeof(Node));
        newNode->data = value;
        newNode->next = stack->top;
        stack->top = newNode;
    }
    
    // 出栈
    int pop(Stack* stack) {
        if (isEmpty(stack)) {
            printf("Stack underflow\n");
            exit(EXIT_FAILURE);
        }
        Node* temp = stack->top;
        int value = temp->data;
        stack->top = temp->next;
        free(temp);
        return value;
    }
    
    // 获取栈顶元素
    int peek(Stack* stack) {
        if (isEmpty(stack)) {
            printf("Stack is empty\n");
            exit(EXIT_FAILURE);
        }
        return stack->top->data;
    }
    
    int main() {
        Stack stack;
        initStack(&stack);
        push(&stack, 10);
        push(&stack, 20);
        push(&stack, 30);
        printf("Top element: %d\n", peek(&stack));  // 输出 30
        printf("Popped element: %d\n", pop(&stack));  // 输出 30
        printf("Top element after pop: %d\n", peek(&stack));  // 输出 20
        return 0;
    }
    
    ```

    **3. 基于C++的栈实现**
    
    C++可以用类封装栈的操作，并支持泛型。
    
    ```cpp
    #include <iostream>
    #include <vector>
    using namespace std;
    
    template<typename T>
    class Stack {
    private:
        vector<T> data;  // 使用动态数组存储栈元素
    public:
        // 判断栈是否为空
        bool isEmpty() const {
            return data.empty();
        }
    
        // 入栈
        void push(const T& value) {
            data.push_back(value);
        }
    
        // 出栈
        T pop() {
            if (isEmpty()) {
                throw runtime_error("Stack underflow");
            }
            T value = data.back();
            data.pop_back();
            return value;
        }
    
        // 获取栈顶元素
        T peek() const {
            if (isEmpty()) {
                throw runtime_error("Stack is empty");
            }
            return data.back();
        }
    };
    
    int main() {
        Stack<int> stack;
        stack.push(10);
        stack.push(20);
        stack.push(30);
        cout << "Top element: " << stack.peek() << endl;  // 输出 30
        cout << "Popped element: " << stack.pop() << endl;  // 输出 30
        cout << "Top element after pop: " << stack.peek() << endl;  // 输出 20
        return 0;
    }
    
    ```
    

**总结：数组与链表实现栈的优缺点**

| 特性 | 数组实现栈 | 链表实现栈 |
| --- | --- | --- |
| 内存使用 | 需要预先分配固定大小的数组 | 动态分配内存，效率更高 |
| 插入/删除时间复杂度 | O(1) | O(1) |
| 空间效率 | 可能有未使用的数组空间 | 每个节点需要额外存储指针 |
| 扩展性 | 不易扩展 | 轻松扩展 |

**栈的应用**

栈广泛用于计算机科学中的许多场景，以下是常见的应用：

1. **函数调用（递归）**
    
    在程序执行过程中，系统会为每个函数调用维护一个栈帧，用于存储函数的参数、局部变量和返回地址。
    
2. **表达式求值**
    - 中缀表达式转后缀表达式（逆波兰表示法）。
    - 计算后缀表达式的值。
3. **对应问题**：前者等待配对，先存入，后输入后者，遍历前者进行配对
    1. **括号匹配：**使用栈检测括号的匹配是否合法，比如 `({[]})` 是合法的，但 `{[)]}` 是不合法的。
4. **深度优先搜索（DFS）**
    
    栈可以用来模拟递归调用，实现图或树的深度优先遍历。
    
5. **浏览器的前进/后退功能**
    
    使用两个栈分别记录前进和后退的历史。
    
6. **实现其他数据结构**
    
    栈是队列、优先队列等其他高级数据结构的重要组件。
    

# 单调栈

### 理解

栈内的元素保持**单调递增**或**单调递减**的性质。这种数据结构常用于处理区间问题，例如**寻找数组中每个元素的下一个更大元素或下一个更小元素**。

- **可以用vector<int>模拟单调栈，利用vector的back函数返回最后面的数（类似栈的栈顶）**

---

单调栈通过**入栈、出栈**操作维护这种单调性，在处理问题时避免了暴力枚举，提高了效率。

以 `[3,4,5,1]` 为例：

```cpp
3, 4, 5, 1
<--------> // 3到1，需要走的路径
<-----> // 4到1，需要走的路径；路径重复
<--> // 5到1，需要走的路径；路径重复
```

我们发现3/4/5最终都是要到达1，而如果它们分别遍历的话，会在“路径上”有重复的部分；哪能不能去掉重复的部分？
是可以的，只需要3在遍历的时候，把4/5 带上一起走，等到了1的时候，再分别算各自的处理逻辑就行。

怎么带？这里就要使用单调栈了，使用单调栈来从3出发，在路上的时候带上4/5。
啥意思？从3出发，找后面比它更小的数，走到4，发现4不小于3，不是3要找的数，就带着4（4要入栈，并且后面以4为头，去找更小的数）；
走到5的逻辑一样也要入栈，这样自然就成为了一个单调递增栈，直到遇到1。这个时候发现1小于5，那我们就可以处理5到1之间诉求，那5处理完了，就要处理4、处理3；如果遇到不满足，就不再处理，继续向后遍历。

（通过上面的逻辑分析，我们可以把 “栈” 比喻成 公交车，大家共同的目标都是向后找更小的站，每到一个站，找满足条件的人下车，不满足的就继续待在车上）

### 用法

1. **找下一个更大元素**

给定一个数组，找到每个元素右边第一个比它大的元素的位置。

2. **找下一个更小元素**

类似地，可以找到右边第一个比当前元素小的位置。

3. **解决区间问题**

- **柱状图中最大矩形面积**
- **温度每日变化问题**（LeetCode 739）
- **滑动窗口中的最大值问题**

---

单调栈的核心思想

1. 遍历数组时，使用栈存储元素的**下标**或**值**。
2. 如果当前元素不满足栈的单调性，就将栈顶元素弹出，同时处理相关结果。
3. 当前元素入栈，保持栈的单调性。

### 板子

**1. 找右边第一个更大的元素**

```cpp
#include <iostream>
#include <vector>
#include <stack>
using namespace std;

vector<int> nextGreaterElement(vector<int>& nums) {
    int n = nums.size();
    vector<int> result(n, -1);  // 初始化结果为 -1，表示右侧没有更大的元素
    stack<int> s;  // 单调递减栈，存储元素下标

    for (int i = 0; i < n; ++i) {
        // 如果当前元素大于栈顶元素，则更新栈顶元素的结果
        while (!s.empty() && nums[i] > nums[s.top()]) {
            result[s.top()] = nums[i];
            s.pop();
        }
        // 当前元素入栈
        s.push(i);
    }
    return result;
}

int main() {
    vector<int> nums = {2, 1, 2, 4, 3};
    vector<int> result = nextGreaterElement(nums);
    for (int x : result) {
        cout << x << " ";  // 输出：4 2 4 -1 -1
    }
    return 0;
}

```

## 例题

1. **柱状图中最大矩形面积**

柱状图问题要求计算由直方图组成的柱子中，最大矩形的面积。

**解法：使用单调递增栈**

- 每当遇到不满足递增顺序的柱子时，弹出栈顶柱子，并计算以其为高的最大矩形面积。

**代码实现：**

```cpp
#include <iostream>
#include <vector>
#include <stack>
using namespace std;

int largestRectangleArea(vector<int>& heights) {
    stack<int> s;  // 单调递增栈，存储柱子的下标
    heights.push_back(0);  // 添加一个高度为 0 的柱子，方便清空栈
    int maxArea = 0;

    for (int i = 0; i < heights.size(); ++i) {
        while (!s.empty() && heights[i] < heights[s.top()]) {
            int h = heights[s.top()];
            s.pop();
            int width = s.empty() ? i : i - s.top() - 1;  // 当前柱子可以扩展的宽度
            maxArea = max(maxArea, h * width);
        }
        s.push(i);
    }
    return maxArea;
}

int main() {
    vector<int> heights = {2, 1, 5, 6, 2, 3};
    cout << largestRectangleArea(heights) << endl;  // 输出：10
    return 0;
}

```

2. **每日温度问题**

给定一组每日温度，计算每一天需要等几天才能等到更高温度。如果没有更高温度，则返回 0。

**解法：单调递减栈**

- 栈中存储温度的下标。
- 当前温度高于栈顶元素时，计算两者的下标差值。

**代码实现：**

```cpp
#include <iostream>
#include <vector>
#include <stack>
using namespace std;

vector<int> dailyTemperatures(vector<int>& temperatures) {
    int n = temperatures.size();
    vector<int> result(n, 0);  // 初始化结果为 0
    stack<int> s;  // 单调递减栈，存储温度下标

    for (int i = 0; i < n; ++i) {
        while (!s.empty() && temperatures[i] > temperatures[s.top()]) {
            int prevIndex = s.top();
            s.pop();
            result[prevIndex] = i - prevIndex;  // 计算等待天数
        }
        s.push(i);
    }
    return result;
}

int main() {
    vector<int> temperatures = {73, 74, 75, 71, 69, 72, 76, 73};
    vector<int> result = dailyTemperatures(temperatures);
    for (int x : result) {
        cout << x << " ";  // 输出：1 1 4 2 1 1 0 0
    }
    return 0;
}

```

单调栈复杂度分析

1. **时间复杂度**：O(n)
    
    每个元素最多入栈一次、出栈一次，总操作次数为 2n。
    
2. **空间复杂度**：O(n)
    
    栈最多存储数组中的所有元素，因此空间复杂度为 O(n)。
    

---

单调栈技巧总结

1. **单调递增/递减栈选择：**
    - 找更大元素：使用单调递减栈。
    - 找更小元素：使用单调递增栈。
2. **存储元素的方式：**
    
    通常存储下标，方便计算与位置相关的结果（如索引差值）。
    
3. **栈的清空：**
    
    添加一个辅助元素（如 0 或无穷大），确保最后可以清空栈并处理所有元素。

**栈的理解**

栈可以通过两种主要方式实现：

1. **基于数组**
数组实现栈时，操作简单，但需要预先分配固定大小的数组。
2. **基于链表**
链表实现的栈动态分配内存，可以扩展到任意大小。
3. **栈的深度**
    
    即栈内元素的数量
