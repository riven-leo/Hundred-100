# 链表
  
链表（Linked List）是一种常见的数据结构，由一组节点（Node）组成。每个节点包含两部分：**数据部分**（存储数据）和**指针部分**（指向下一个节点的引用）。链表通过指针将节点连接在一起，形成线性结构。与数组不同，链表的存储位置不连续。  

数值+一个指针
# 分类
单链表、双向链表、循环链表、双向循环链表、多级链表（一个节点可能指向多个链表或嵌套结构）、跳表(skip list)（链表中增加了索引层，以提高查找效率。）
    
循环链表：尾节点指针指向头节点

双向链表：prev指针、数值和next指针

- 链表的优缺点
    
    **优点：**
    
    1. 动态内存分配：链表的大小不固定，可以随时扩展或缩减。
    2. 插入和删除效率高：不需要移动其他元素，时间复杂度为 O(1)。
    
    **缺点：**
    
    3. 查找效率低：需要从头节点开始逐个遍历，时间复杂度为 O(n)。
    4. 内存开销大：每个节点都需要额外存储指针。

    class Solution {
        public:
            ListNode* removeNthFromEnd(ListNode* head, int n) {

                    fast = fast->next;

List(C++STL)(Standard Template Library)

双向链表容器与其他容器（如 `vector` 或 `deque`）不同，`list` 通过节点（node）链接起来，适合在中间插入或删除元素的场景，而不需要重新分配和复制整个容器。

`list`的基本特性

1. **双向链表**：`list` 中的元素通过双向链表连接，每个节点都有指向前一个元素和下一个元素的指针。
2. **动态大小**：`list` 的大小是动态的，可以随时增加或删除元素，而不需要重新分配内存。
3. **非连续内存**：与 `vector` 或 `array` 不同，`list` 的元素不是存储在连续的内存空间中的，因此在访问元素时需要通过指针遍历。

List主要操作

插入元素

- `push_back(value)`：在末尾添加元素。
- `push_front(value)`：在前面添加元素。
- `insert(position, value)`：在指定位置插入元素。

删除元素(pop弹出)

- `pop_back()`：删除末尾元素。
- `pop_front()`：删除前面元素。
- `erase(position)`：删除指定位置的元素。
- `erase(first, last)`：删除指定范围内的元素。

访问元素

- `front()`：返回容器的第一个元素。
- `back()`：返回容器的最后一个元素。
- `begin()`：返回指向容器首元素的迭代器。
- `end()`：返回指向容器尾元素后一个位置的迭代器。

其他操作

- `size()`：返回元素的个数。
- `empty()`：判断容器是否为空。
- `clear()`：清空容器中的所有元素。
- `sort()`：对容器进行排序。
- `reverse()`：反转容器中的元素顺序。

```cpp
#include <iostream>
#include <list>

int main() {
    // 创建一个空的list容器
    std::list<int> myList;

    // 向末尾添加元素
    myList.push_back(10);
    myList.push_back(20);
    myList.push_back(30);

    // 向前添加元素
    myList.push_front(5);

    // 删除前端元素
    myList.pop_front();

    // 删除末尾元素
    myList.pop_back();

    // 迭代并打印元素
    for (int val : myList) {
        std::cout << val << " ";
    }

    // 输出：10 20
    return 0;
}
使用场景
```

`list` 适合需要频繁在中间插入和删除元素的情况，因为它在插入和删除操作时比 `vector` 更高效（`vector` 需要移动元素，而 `list` 只需要修改指针）。但是，`list` 在随机访问元素时效率较差，因为访问某个元素需要从头或尾开始遍历

# 深入学习链表

链表作为一种基础的数据结构，尽管看似简单，但其背后有许多细节和优化技巧可以深入学习。以下是更深入了解链表的一些方向。

---

### 1. **链表的类型及实现差异**

- **静态链表**
    
    静态链表用数组模拟链表，指针被数组下标代替。它在内存受限的嵌入式系统中很常用。
    
    **示例：**
    
    ```c
    typedef struct {
        int data;
        int next;  // 存储下一个节点的数组下标
    } StaticNode;
    StaticNode staticList[100];  // 固定大小的静态链表
    
    ```
    
- **双向循环链表**
    
    双向循环链表在许多实际应用中非常重要，比如LRU缓存机制。其尾节点指向头节点，形成一个环，头尾可以快速切换。
    

---

### 2. **复杂操作的实现**

- **链表排序**
    
    链表排序通常不能直接使用数组中的快速排序（因其需要随机访问）。常用的排序算法包括：
    
    1. **归并排序**：链表的归并排序因其天然的分裂特性（快慢指针找到中点）而高效。
    2. **插入排序**：适合小规模链表排序。
    
    **归并排序示例：**
    
    ```cpp
    Node* merge(Node* left, Node* right) {
        if (!left) return right;
        if (!right) return left;
        if (left->data < right->data) {
            left->next = merge(left->next, right);
            return left;
        } else {
            right->next = merge(left, right->next);
            return right;
        }
    }
    
    Node* mergeSort(Node* head) {
        if (!head || !head->next) return head;
        Node* slow = head, *fast = head, *prev = nullptr;
        while (fast && fast->next) {
            prev = slow;
            slow = slow->next;
            fast = fast->next->next;
        }
        prev->next = nullptr;  // 分割链表
        return merge(mergeSort(head), mergeSort(slow));
    }
    
    ```
    
- **链表反转**
    
    链表反转是一种经典操作，常见方法有递归和迭代。
    
    **递归实现：**
    
    ```cpp
    Node* reverse(Node* head) {
        if (!head || !head->next) return head;
        Node* newHead = reverse(head->next);
        head->next->next = head;
        head->next = nullptr;
        return newHead;
    }
    ```
    
    **迭代实现：**
    
    ```cpp
    Node* reverse(Node* head) {
        Node* prev = nullptr;
        Node* current = head;
        while (current) {
            Node* next = current->next;
            current->next = prev;
            prev = current;
            current = next;
        }
        return prev;
    }
    ```

### 5. **比较链表和其他数据结构**

- 与 **数组**：
    - 链表适合频繁插入/删除操作。
    - 数组适合随机访问和批量操作。
- 与 **树**：
    - 链表更简单，适合线性关系。
    - 树更复杂，适合表示层级关系。
- 与 **栈和队列**：
    - 链表可以高效实现栈和队列（如单链表实现栈，双向链表实现双端队列）。

### 7. **挑战问题**

1. 如何检测链表中是否有环？
    
    **方法**：使用快慢指针。如果快指针和慢指针相遇，则存在环。
    
2. 如何在 O(1) 时间复杂度删除给定的链表节点？
    
    **方法**：将目标节点的值替换为下一个节点的值，然后删除下一个节点（仅适用于非尾节点）。
