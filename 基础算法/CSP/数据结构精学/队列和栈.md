lower_bound upper_bound基本功能
在已排序的区间 [first, last) 中，upper_bound 用于查找第一个大于（>）给定值 val 的元素，并返回该元素的迭代器（或地址）。如果所有元素都小于或等于 val，则返回 last 位置。

函数名	        升序数组中的查找条件	            未找到时的返回值
lower_bound	    第一个大于或等于（≥）val 的元素	    last
upper_bound	    第一个严格大于（>）val 的元素	    last


queue常用函数：
push() pop() front() back()

std::vector 来模拟队列（Queue），移除队（即模拟 pop() 操作）

```C++
#include <vector>

std::vector<int> q;

// 模拟 push() 入队
q.push_back(10);
q.push_back(20);

// 模拟 pop() 移出第一个元素
if (!q.empty()) {
    q.erase(q.begin()); // 移除索引为 0 的元素
}
```

但复杂度高O(n)
所以采用双指针-假删除：

```C++
#include <vector>

std::vector<int> q;
int head = 0; // 记录队头位置的的索引

q.push_back(10); // 入队
q.push_back(20);

// 查看队头
int front_element = q[head];

// 移除第一个元素（出队）
if (head < q.size()) {
    head++; // 仅仅将指针后移，时间复杂度为 O(1)
}

// 此时判断队列是否为空
bool is_empty = (head == q.size());
```
