在操作系统的进程内存布局中，不同区域的内存分配方向是不同的：
• 栈（Stack）： 通常用于存放函数的局部变量和参数。绝大多数 CPU 架构（如 x86、ARM）的栈都是向低地址增长的。这意味着，先定义的变量处于高地址，后定义的变量处于低地址。
• 堆（Heap）： 通常用于程序动态分配内存（如 C 语言的 malloc 或 C++ 的 new）。堆空间通常是向高地址增长的，即先分配的在低地址，后分配的在高地址。

动态分配内存
```C++
#incldue <stdio.h>
#include <stdlib.h>
int main() {
    int n = 10;
    // malloc return void pointer default, 自动强转成对应类型in c
    // sizeof()里写*ptr，而不写int类型名，可以自适应ptr指针的类型
    // 给ptr指针分配10个int大小的内存空间，即40字节，可以存放10个int类型数据
    int* ptr = malloc(10 * sizeof(*ptr));

    // 分配内存失败
    if (ptr == NULL) return -1;

    // 使用内存
    for (int i = 0; i < n; i++) {
        ptr[i] = i + 1;
        printf("%d ", ptr[i]);
    }
    printf("\n");
    
    // 养成好习惯，释放内存后置NULL, 防止野指针
    free(ptr);
    ptr = NULL;
    return 0;
}
int main() {
    int n = 10;
    // calloc将每个字节初始化为零
    int* ptr = calloc(10, sizeof(*ptr));

    if (ptr == NULL) return -1;

    for (int i = 0; i < n; i++) {
        printf("%d ", ptr[i]); // 输出全为0
    }

    free(ptr);
    ptr = NULL;
    return 0;
}
```
