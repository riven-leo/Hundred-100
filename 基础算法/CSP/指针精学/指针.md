4. 字节序：
数据存储在内存地址的形式
小端（现在常见）：数据低位存在内存低位
大端：数据高位存在内存低位

大端模式符合人类直觉，而小端模式符合计算机的运算逻辑
• 计算机内部（如 CPU、内存）：普遍采用小端模式，为了追求极致的硬件运算效率。
• 人类交互与传输（如网络协议 IP、文件存储）：普遍采用大端模式（网络字节序），因为数据在传输和排查时，必须方便人类阅读和理解。

小端好处：
因为加减乘除从低位开始运算，强转方便只取低位，后面多的位不管了，如int强转char，后三个字节不管，所以数值会变小
0x12345678 0x12符合人类书写习惯 高位在前
而计算机内存从低位到高位增加，和序号一样，从0到高

**盲目把 int* 理解为一个不可分割的整体出现严重错误或误解**
```C++
1. 同一行声明多个变量（最经典陷阱）

编译器在语法解析时，星号 * 实际上是结合在变量名上，而不是类型上。
• 错误理解：int* p1, p2; —— 许多人以为 int* 是整体，所以 p1 和 p2 都是指针。
• 实际情况：只有 p1 是 int*（整型指针），而 p2 只是一个普通的 int（整型变量）。
• 正确写法：如果想同时声明两个指针，必须写成 int *p1, *p2;（或者直接分两行写）。

2. 结合 const 修饰符（极易混淆）

如果你习惯把 int* 当作一个整体，就很难正确理解“常量指针”和“指针常量”的区别。
• 示例 A：const int* p; 或 int const* p;
	• 含义：*p 是常量（不能通过 p 修改指向的值），但指针 p 本身可以指向别的地址。
• 示例 B：int* const p;
	• 含义：p 是常量（指针本身不能改变指向），但可以通过 *p 修改它指向的值。
• 为什么会出错：如果把 int* 当整体，const 放在前面或后面容易让人产生“整个指针类型都是只读”的错觉，而忽略了究竟是指针本身只读，还是指向的数据只读。

3. 结合 typedef 别名（隐蔽的高危陷阱）

使用 typedef 定义指针别名后，再配合 const 修饰，会产生与文本替换完全不同的结果。
• 假设定义：typedef int* IntPtr;
• 误区代码：const IntPtr p;
	• 直觉以为：把 IntPtr 替换为 int*，以为它等价于 const int* p（指向常量的指针）。
	• 编译器实际解析：IntPtr 是一个完整的指针类型，const 修饰的是这个指针本身，因此它实际上等价于 int* const p（指针常量，指针不能再指向别处，但可以修改指向的值）！

总结

正是因为上述语法机制，很多资深开发者（尤其是 C 程序员）坚持使用 int *p 的写法——因为 * 在语法树中本来就是修饰变量名 p 的，而不是修饰 int 的。

```C++
“从右向左阅读法”（也叫“右左法则”，Right-Left Rule）是 C/C++ 中用来精准拆解复杂变量声明的核心技巧。它的基本规则是：从变量名开始，先往右看，再往左看；遇到括号就先处理括号内部。
在遇到 const 和指针的组合时，不需要死记硬背“常量指针”或“指针常量”这些拗口的名词，直接从变量名开始往左读就能一秒看懂。

核心口诀：遇 * 读作“指针”，遇 const 读作“常量”

下面我们用这个法则来逐一拆解几种最常见的组合：

1. const int* p;

• 从变量名 p 开始往左看：
	1. 先遇到 * \(\rightarrow \) p 是一个指针。
	2. 再遇到 int \(\rightarrow \) 指向一个整型（int）。
	3. 最后遇到 const \(\rightarrow \) 这个整型是常量。
• 连起来读：p 是一个指针，指向一个常量的整型（即不能通过 *p 修改数据，但指针 p 本身可以指向别处）。

2. int const* p;

• 从变量名 p 开始往左看：
	1. 先遇到 * \(\rightarrow \) p 是一个指针。
	2. 再遇到 const \(\rightarrow \) 指向一个常量。
	3. 最后遇到 int \(\rightarrow \) 这个常量是整型的。
• 连起来读：p 是一个指针，指向一个整型的常量。
• 结论：它和第一种写法 const int* p; 完全等价！

3. int* const p;

• 从变量名 p 开始往左看：
	1. 先遇到 const \(\rightarrow \) p 是一个常量（说明 p 自身的值不能变）。
	2. 再遇到 * \(\rightarrow \) 这个常量是一个指针。
	3. 最后遇到 int \(\rightarrow \) 指向一个整型。
• 连起来读：p 是一个常量指针，指向一个整型（即指针 p 本身不能改变指向，但可以通过 *p 修改指向的值）。

4. const int* const p;

• 从变量名 p 开始往左看：
	1. 遇到第一个 const \(\rightarrow \) p 是一个常量。
	2. 遇到 * \(\rightarrow \) 这个常量是一个指针。
	3. 遇到 int 和第二个 const \(\rightarrow \) 指向一个整型的常量。
• 连起来读：p 是一个常量指针，指向一个整型常量（即指针不能改指向，数据也不能通过指针修改）。

进阶挑战：加入数组和函数括号

当声明中出现 []（数组）或 ()（函数）时，遵循“先右后左，括号优先”的原则：
• 示例 1：int* arr[5];（指针数组）
	• 从 arr 开始，先往右看遇到 [5] \(\rightarrow \) arr 是包含 5 个元素的数组。
	• 再往左看遇到 * 和 int \(\rightarrow \) 数组里的每个元素都是 指向 int 的指针。
• 示例 2：int (*arr)[5];（数组指针）
	• arr 被括号括起来了，先看括号里面：*arr \(\rightarrow \) arr 是一个指针。
	• 出括号后先往右看遇到 [5] \(\rightarrow \) 指向一个包含 5 个元素的数组。
	• 再往左看遇到 int \(\rightarrow \) 数组里的元素是 int 类型。
