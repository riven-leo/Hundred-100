1. 指针变量的大小与平台相关：32位系统下为4字节，64位系统下为8字节，与指向的类型无关。
```C++
#include 
int main()
{
    printf("%zd\n", sizeof(int*));
	printf("%zd\n", sizeof(char*));
	printf("%zd\n", sizeof(short*));
	printf("%zd\n", sizeof(double*));
	return 0;
}// 输出都为4或8

2. 指针运算步长：int* + 1跳过4字节，char* + 1跳过1字节。
#include 
int main()
{
	int a = 5;
	int* p1 = &a;
	char* p2 = &a;
	printf("%p\n", p1);     // 0080FA90
	printf("%p\n", p1 + 1); // 0080FA94
	printf("%p\n", p2);
	printf("%p\n", p2 + 1); // 0080FA91
	return 0;
}
```.
3. const修饰变量可防止直接修改，但通过指针仍可绕过。为此，C语言提供了两种const指针模式：
const int* p：不能通过*p修改值，但可以改变p的指向。
int* const p：不能改变p的指向，但可以通过*p修改值。
const int* const p：两者都不能修改。

4. 字节序：
数据存储在内存地址的形式
小端（现在常见）：数据低位存在内存低位
大端：数据高位存在内存低位

大端模式符合人类直觉，而小端模式符合计算机的运算逻辑
• 计算机内部（如 CPU、内存）：普遍采用小端模式，为了追求极致的硬件运算效率。
• 人类交互与传输（如网络协议 IP、文件存储）：普遍采用大端模式（网络字节序），因为数据在传输和排查时，必须方便人类阅读和理解。

小端好处：
因为加减乘除从低位开始运算，强转方便只取低位，后面多的位不管了，如int强转char，后三个字节不管，所以数值会变小
0x12345678 0x12符合人类书写习惯 高位在前
而计算机内存从低位到高位增加，和序号一样，从0到高
