MyClass* obj = new MyClass(); 
MyClass* obj2 = new MyClass("hello", 42); 

// 使用完后必须释放
delete p1;
delete p2;

delete obj2;

**new 与 malloc 的主要区别**
特性	new (C++)	malloc (C)
类型	运算符（Operator）	库函数 (<stdlib.h>)
内存返回类型	强类型指针（如 int*）	通用指针 void*，需要强制类型转换

**时间复杂度计算**

### **1. 观察操作的核心模式**

- **线性遍历**：如果操作涉及遍历数据结构的 **一半元素**（如顺序表插入、删除中间元素），平均时间复杂度通常为 **O(n)**。
- **分治/二分**：若每次操作将数据规模 **减半**（如二分查找、归并排序），时间复杂度一般为 **O(log n)**。
- **嵌套循环**：循环层数直接决定复杂度。例如双重循环遍历二维数组，时间复杂度为 **O(n²)**。

---

### **2. 平均情况的简化计算**

假设操作位置是 **均匀随机分布** 的：

- **顺序表插入**：向长度为 `n` 的顺序表中插入元素时，有 `n+1` 个可能的位置（包括头尾）。
    - **移动元素次数的期望值** = `(0 + 1 + 2 + ... + n) / (n+1)` ≈ `n/2`
    - 因此平均时间复杂度为 **O(n)**（系数 `1/2` 在大 O 中省略）。

---

### **3. 经验法则**

- **线性结构**（数组、链表）：插入/删除平均需操作 **一半元素** → **O(n)**。
- **哈希表**：冲突较少时，插入/查找平均为 **O(1)**（均匀哈希假设）。
- **树结构**（平衡二叉搜索树）：每次操作缩小一半搜索范围 → **O(log n)**。

---

### **4. 快速判断步骤**

1. **识别核心操作**：找到算法中重复执行的基本操作（如元素移动、比较）。
2. **分析循环次数**：观察循环与输入规模 `n` 的关系（单层循环 → O(n)，双重循环 → O(n²)）。
3. **假设均匀分布**：若操作位置随机，用期望值简化计算（如取中间值 `n/2`）。
4. **对比常见模式**：直接匹配经典算法的时间复杂度（如排序、查找算法）。

---

### **示例：顺序表插入的快速分析**

1. **核心操作**：将插入位置后的元素逐个后移。
2. **平均情况假设**：插入位置在 `0` 到 `n` 之间均匀分布。
3. **估算移动次数**：平均需移动 `n/2` 个元素。
4. **结论**：时间复杂度为 **O(n)**。

---

### **注意事项**

- **大 O 表示法忽略系数**：即使平均移动次数是 `n/2`，仍简化为 **O(n)**。
- **极端情况**：若插入末尾（移动 0 次）或头部（移动 `n` 次），时间复杂度仍为 **O(n)**。
- **严谨场景**：需严格计算期望值（如求和公式），但快速估算时可直接取中间值。

这种方法能覆盖大多数场景，适合面试、考试或快速分析！

string add(string a, string b, string& ans) {
    //判断字符串长度
    int lena = a.size();
    int lenb = b.size();
    int lmax = max(lena, lenb);
    //倒置字符串，并转换成单个数字储存在数组中
    for (int i = 0; i < lena; i++) {
        na[lena - i - 1] = a[i] - '0';
    }
    for (int i = 0; i < lenb; i++) {
        nb[lenb - i - 1] = b[i] - '0';
    }
    //进位
    for (int i = 0; i < lmax; i++) {
        na[i] += nb[i];
        na[i + 1] += na[i] / 10;
        na[i] %= 10;
    }
    //长度判断
    if (na[lmax]) lmax++;
    //转ans字符串
    for (int i = lmax-1; i >= 0; i--) {
        ans += na[i] + '0';
    }
    return ans;
}

**前后缀和**
前缀和是指数组中从起始位置到某个位置的元素之和，后缀和是指数组中从某个位置到结尾位置的元素之和。

前缀和和后缀和通常用于优化区间求和问题，通过预处理数组，能够在常数时间内计算任意区间的和，从而提高效率。

前缀和和后缀和在解决多种问题时都非常有用，特别是在需要频繁查询数组区间和的场景，常见的用途包括：

1. **区间和查询**：通过预计算前缀和或后缀和，可以在常数时间内求出任意区间的和，避免每次查询时都进行重复计算。
2. **动态规划优化**：在一些动态规划问题中，前缀和和后缀和可以帮助快速计算状态转移的值，减少时间复杂度。
3. **差分数组**：在处理区间修改问题时，可以通过前缀和来实现高效的更新操作，避免重复遍历更新区间。
4. **算法竞赛**：在各种算法题目中，前缀和和后缀和经常用于加速求解过程，特别是在涉及大数据量的情况下。

尤其是在需要多次查询和更新数组的场景下。
