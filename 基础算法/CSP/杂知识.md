在 C++ 中，<utility> 头文件直译为“实用工具库”或“辅助工具库”
如果把 C++ 标准库比作一间大工厂：
• <vector> 和 <map> 是专门的大型流水线设备（用来批量存储和管理数据）。
• <algorithm> 是具体的工艺流程手册（负责排序、查找等计算）。
• 而 <utility> 就是工人们腰带上挂的螺丝刀、胶带和润滑剂

1. <iomanip>（格式操纵符）

• std::setw(n)：设置宽度，限制下一次输出的字符宽度（默认右对齐，不足补空格）。
• std::setprecision(n)：设置精度，控制浮点数的有效数字位数（配合 std::fixed 可固定小数点后位数）。
• std::setfill(ch)：设置填充，配合 setw 使用，用指定字符填充不足的宽度。
• std::put_money(val) / std::get_money(val)：货币格式化，按本地化标准输出/输入货币。

2. <utility>（通用工具）

• std::pair<T1, T2>：键值对结构，将两个不同类型的数据组合成一个整体（通过 .first 和 .second 访问）。
• std::make_pair(v1, v2)：创建键值对，便捷地生成一个 std::pair 对象。
• std::move(obj)：移动语义，将对象强制转换为右值，用于触发高效的资源转移（避免深拷贝）。
• std::forward(obj)：完美转发，在泛型模板中原封不动地传递参数的左/右值属性。
• std::swap(a, b)：交换变量，高效交换两个变量的值（C++11 后从 <algorithm> 移入）。

3. <algorithm>（标准算法）

• 排序与查找：
	• std::sort(start, end)：高效排序，默认对区间内元素进行升序排列（快排/内省排序）。
	• std::binary_search(start, end, val)：二分查找，在已排序区间中检查元素是否存在（返回 bool）。
	• std::lower_bound(start, end, val)：查找下界，返回第一个大于或等于目标值的迭代器。
• 修改与变换：
	• std::reverse(start, end)：反转区间，将区间内的元素顺序完全颠倒。
	• std::unique(start, end)：区域去重，将相邻的重复元素移到末尾，常配合容器的 erase 彻底删除。
	• std::fill(start, end, val)：区间填充，用同一个值填满指定区间。
• 统计与搜索：
	• std::max_element(start, end) / std::min_element(start, end)：找最值，返回区间内最大/最小元素的迭代器。
	• std::find(start, end, val)：线性查找，在区间内查找第一个等于目标的元素。
	• std::count(start, end, val)：计数统计，统计目标值在区间内出现的次数。

4. <cmath>（数学计算）

• std::abs(x) / std::fabs(x)：求绝对值（C++ 中直接用 std::abs 即可支持浮点和整数）。
• std::sqrt(x) / std::cbrt(x)：开平方 / 开立方。
• std::pow(x, y)：求幂次，计算 \(x^{y}\) 的值。
• std::ceil(x) / std::floor(x) / std::round(x)：向上取整 / 向下取整 / 四舍五入。
• std::sin(x) / std::cos(x) / std::tan(x)：三角函数（注意：传入的参数 x 必须是弧度制）。
• std::atan2(y, x)：反正切函数，能根据 y 和 x 的正负号自动判断象限，比 atan 更安全常用。
• std::log(x) / std::log10(x)：对数计算，分别计算以 \(e\) 为底（自然对数）和以 \(10\) 为底的对数。
