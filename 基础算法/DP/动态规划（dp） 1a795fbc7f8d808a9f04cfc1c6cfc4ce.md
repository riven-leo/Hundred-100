# 概念定义

动态规划是一种通过将复杂问题分解为相互重叠的子问题，存储并复用子问题的解，从而高效优化整体解的算法策略。

动态规划（Dynamic Programming, DP）是一种通过将问题分解成子问题并保存中间结果来提高计算效率的算法设计方法。它适用于那些可以通过子问题的解来构建整个问题解的问题。

# 用于解决

1. **最优化问题**：这些问题的目标是找到某个优化目标的最优解，通常是最大化或最小化某个值。典型的例子包括：
    - **背包问题**：给定一组物品，每个物品有一个重量和价值，在给定最大承重的情况下，选择哪些物品使得总价值最大。
    - **最短路径问题**：比如，找出从一个点到另一个点的最短路径（如Dijkstra算法）。
    - **最长公共子序列（LCS）**：在两个序列中找出最长的公共子序列。
2. **计数问题**：这些问题的目标是计算不同的排列、组合或可能的方式。常见的例子包括：
    - **不同的路径问题**：如从一个格点到另一个格点有多少种不同的路径。
    - **斐波那契数列**：通过递推计算斐波那契数列的第n项。
    - **子集和问题**：给定一个集合，求和等于目标数值的子集个数。
3. **决策问题**：这些问题要求通过动态选择决策序列来解决，通常具有“最优子结构”特性。典型例子：
    - **矩阵链乘法问题**：给定多个矩阵的乘法顺序，求出最小的乘法代价。
    - **股票买卖问题**：如何买卖股票以获取最大收益。
4. **分割问题**：当问题可以通过分割成子问题来简化时，动态规划也能提供有效的解决方案。例如：
    - **整数拆分问题**：如何将一个整数分解成若干个整数的和，且这些整数的乘积最大。
    - **单词拆分问题**：给定一个字符串，能否将其分割成字典中存在的单词。

动态规划的关键在于**最优子结构**和**重叠子问题**：

- **最优子结构**：问题的最优解可以由子问题的最优解来构成。
- **重叠子问题**：问题的子问题在求解过程中会重复出现。

通过记忆化（Memoization）或表格化（Tabulation）来保存已经计算过的子问题结果，避免重复计算，从而大幅提高效率。

# 板子

```cpp
#include <vector>
#include <algorithm> // 用于max/min等操作

// 示例：一维DP（以斐波那契数列为例）
int fibonacci(int n) {
    if (n <= 1) return n;
    std::vector<int> dp(n + 1); // DP数组
    dp[0] = 0; dp[1] = 1;      // 初始化
    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2]; // 状态转移方程
    }
    return dp[n];
}

// 示例：二维DP（以0-1背包问题为例）
int knapsack(int W, const std::vector<int>& weights, const std::vector<int>& values) {
    int n = weights.size();
    std::vector<std::vector<int>> dp(n + 1, std::vector<int>(W + 1, 0)); // 二维DP表

    for (int i = 1; i <= n; i++) {
        for (int w = 1; w <= W; w++) {
            if (weights[i-1] > w) {
                dp[i][w] = dp[i-1][w]; // 无法放入
            } else {
                // 选择放入或不放入的最优解
                dp[i][w] = std::max(
                    dp[i-1][w],
                    dp[i-1][w - weights[i-1]] + values[i-1]
                );
            }
        }
    }
    return dp[n][W];
}

/* 使用要点：
1. **定义状态**：明确dp[i]或dp[i][j]的含义
2. **初始化**：边界条件（如dp[0]、dp[0][j]等）
3. **状态转移方程**：核心逻辑（递推关系）
4. **空间优化**：根据问题决定是否用滚动数组压缩维度
*/
```

---

常见问题适配：

1. **一维DP**（如斐波那契、爬楼梯）：
    
    ```cpp
    vector<int> dp(n+1);
    ```
    
2. **二维DP**（如LCS、编辑距离）：
    
    ```cpp
    vector<vector<int>> dp(m+1, vector<int>(n+1, 0));
    ```
    
3. **滚动数组优化**（空间压缩）：
    
    ```cpp
    vector<int> dp(W+1); // 替代二维数组
    ```
    

---

示例调用：

```cpp
int main() {
    // 斐波那契测试
    cout << "Fib(5): " << fibonacci(5) << endl; // 输出5

    // 背包测试
    vector<int> weights = {2, 3, 4, 5};
    vector<int> values = {3, 4, 5, 6};
    cout << "Knapsack(8): " << knapsack(8, weights, values) << endl; // 输出10
    return 0;
}
```

动态规划的状态定义和转移方程确实是核心，而**“穷举法 → 记忆化搜索 → 迭代形式”**是动态规划从暴力到优化的完整推导链路，具体关系如下：

---

1. **穷举法（暴力递归）**

- **核心**：直接通过递归遍历所有可能的解（如树形展开），不记录中间结果。
- **问题**：存在大量重复计算，时间复杂度指数级增长（如斐波那契的 `O(2^n)`）。

```cpp
int fib(int n) {
    if (n <= 1) return n;
    return fib(n-1) + fib(n-2); // 重复计算fib(n-2)、fib(n-3)...
}

```

---

2. **记忆化搜索（Memoization，自顶向下）**

- **核心**：在递归基础上，用哈希表或数组**缓存已计算的子问题结果**，避免重复计算。
- **优点**：保留递归的直观性，时间复杂度降至 `O(n)`。
- **关键**：状态定义与动态规划一致，但计算顺序由递归隐式决定。

```cpp
int fib_memo(int n, vector<int>& memo) {
    if (n <= 1) return n;
    if (memo[n] != -1) return memo[n]; // 查缓存
    memo[n] = fib_memo(n-1, memo) + fib_memo(n-2, memo); // 存缓存
    return memo[n];
}

```

---

3. **迭代形式（动态规划，自底向上）**

- **核心**：**显式定义状态表**（如 `dp[]` 数组），按依赖顺序从基础状态递推到目标状态。
- **优点**：避免递归栈开销，空间可优化（如滚动数组），时间复杂度同为 `O(n)`。
- **关键**：状态转移方程直接对应递归中的子问题拆分逻辑。

```cpp
int fib_dp(int n) {
    vector<int> dp(n+1);
    dp[0]=0; dp[1]=1;
    for(int i=2; i<=n; i++)
        dp[i] = dp[i-1] + dp[i-2]; // 显式填充状态表
    return dp[n];
}

```

---

三者的本质联系

| **方法** | **方向** | **计算顺序** | **空间复杂度** | **适用场景** |
| --- | --- | --- | --- | --- |
| 暴力递归 | 自顶向下 | 由问题分解隐式决定 | 无优化 | 小规模问题，验证思路 |
| 记忆化搜索 | 自顶向下 | 隐式（递归驱动） | `O(n)` | 状态依赖复杂，难以直接迭代 |
| 动态规划(迭代) | 自底向上 | 显式按顺序填充 | 可优化至 `O(1)` | 状态依赖清晰，需空间优化 |

---

为什么需要这种递进？

1. **设计验证**：先通过暴力递归明确状态定义和转移逻辑，确保问题可分解。
2. **优化路径**：记忆化搜索是递归到动态规划的过渡，保留递归思维的同时引入缓存。
3. **工程落地**：迭代形式更高效且稳定（避免栈溢出），尤其适用于大规模问题。

---

示例：以爬楼梯问题（每次1/2步）说明

- **暴力递归**：`f(n) = f(n-1) + f(n-2)`，大量重复计算。
- **记忆化搜索**：递归时缓存 `f(n)`，每个状态只算一次。
- **动态规划**：从 `f(0)=1, f(1)=1` 开始循环计算到 `f(n)`。

三者**共享同一状态转移方程**，但实现方式不同，最终殊途同归。
