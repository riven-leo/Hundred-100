# BF（brute force）算法

- 暴力匹配算法适合作为字符串匹配的入门学习
- 作为其他高效算法（如KMP、BM算法）的基础理解

## 一句话概括

是一种枚举所有可能解并逐一验证的算法，适用于问题规模较小或无更优解法的情况。

### **用法**

BF 的核心思想是**穷举所有可能的解**，然后检查每个解是否满足条件。一般用于：

1. **遍历所有组合**（如字符串匹配、子集枚举）
2. **模拟所有可能情况**（如棋局搜索、路径查找）
3. **简单优化问题**（如求最大/最小值，找特定排列）

### **用途**

BF算法常用于以下场景：

- **字符串匹配**（如朴素匹配算法）
- **排列组合问题**（如全排列、子集生成）
- **搜索问题**（如迷宫求解、暴力破解密码）
- **图论**（如最短路径的暴力搜索、图的遍历）
- **博弈问题**（如遍历所有棋步）

虽然BF算法容易理解和实现，但在大规模数据下效率低，需要优化或结合剪枝、启发式搜索等方法提升性能。

## 概括性板子

暴力搜索算法（BF算法）的通用模板可以概括为以下两个步骤：

1. **枚举候选解**
    
    对于给定问题，通过循环、递归或位运算等方式生成所有可能的候选解。
    
2. **验证候选解**
    
    对于每个候选解，检查它是否满足问题的条件或目标要求，符合要求则进行记录或处理。
    

用伪代码表示如下：

```cpp
for candidate in 所有候选解集合:
    if candidate 满足条件:
        记录或处理 candidate
```

这种方法简单直接，适用于问题规模较小或没有更高效算法的场景，但在候选解数量庞大时容易导致计算复杂度过高。

## 例题

### **1. 朴素字符串匹配（暴力搜索）**

适用于在文本 `text` 中查找 `pattern` 的位置，时间复杂度为 **O(nm)**（n为文本长度，m为模式长度）。

```cpp
#include <iostream>
#include <string>
using namespace std;

void bruteForceSearch(const string &text, const string &pattern) {
    int n = text.size(), m = pattern.size();
    for (int i = 0; i <= n - m; i++) { // 遍历所有可能的起点
        int j = 0;
        while (j < m && text[i + j] == pattern[j]) j++; // 逐字符匹配
        if (j == m) cout << "Pattern found at index " << i << endl;
    }
}

int main() {
    string text = "abcdeabcd";
    string pattern = "bcd";
    bruteForceSearch(text, pattern);
    return 0;
}

```

### **2. 全排列生成（递归+暴力枚举）**

用于生成 `nums` 的所有排列，适用于小规模数据（O(n!)）。

```cpp
#include <iostream>
#include <vector>
using namespace std;

void permute(vector<int> &nums, int l, int r) {
    if (l == r) { // 递归出口
        for (int num : nums) cout << num << " ";
        cout << endl;
        return;
    }
    for (int i = l; i <= r; i++) {
        swap(nums[l], nums[i]); // 交换
        permute(nums, l + 1, r);
        swap(nums[l], nums[i]); // 还原
    }
}

int main() {
    vector<int> nums = {1, 2, 3};
    permute(nums, 0, nums.size() - 1);
    return 0;
}

```

### **3. 子集枚举（位运算暴力）**

用于生成 `nums` 的所有子集，时间复杂度 **O(2^n)**，适用于数据规模较小的情况。

```cpp
#include <iostream>
#include <vector>
using namespace std;

void generateSubsets(vector<int> &nums) {
    int n = nums.size();
    int total = 1 << n; // 2^n 种情况
    for (int mask = 0; mask < total; mask++) {
        vector<int> subset;
        for (int i = 0; i < n; i++) {
            if (mask & (1 << i)) subset.push_back(nums[i]); // 判断是否选中该元素
        }
        cout << "{ ";
        for (int num : subset) cout << num << " ";
        cout << "}\n";
    }
}

int main() {
    vector<int> nums = {1, 2, 3};
    generateSubsets(nums);
    return 0;
}

```

### **4. 暴力求解最近点对（O(n^2))**

适用于小规模点对距离计算，通常需要分治优化为 O(n log n)。

```cpp
#include <iostream>
#include <vector>
#include <cmath>
using namespace std;

struct Point {
    double x, y;
};

double dist(const Point &a, const Point &b) {
    return sqrt((a.x - b.x) * (a.x - b.x) + (a.y - b.y) * (a.y - b.y));
}

double bruteForceClosestPair(vector<Point> &points) {
    int n = points.size();
    double minDist = 1e9;
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            minDist = min(minDist, dist(points[i], points[j]));
        }
    }
    return minDist;
}

int main() {
    vector<Point> points = {{0, 0}, {1, 1}, {3, 4}, {6, 8}};
    cout << "Closest distance: " << bruteForceClosestPair(points) << endl;
    return 0;
}

```

BF（暴力搜索）适用于数据规模较小的情况，通常作为**基准算法**，可以结合剪枝、优化搜索顺序或其他高效算法（如二分、分治）提升效率。

# KMP算法

- 精髓在于通过预处理得出next[j]数组，使得永远不回溯i （指向主串的指针），让i 一直向前进
- next里装的是 j 指针跳过的字符个数 也可以理解为 j 指针回到的位置

## 一句话概括

KMP算法通过预处理模式串生成部分匹配表（next数组），在匹配失败时利用该表跳过不必要的字符比较，从而在保持主串指针不回溯的前提下实现高效的字符串搜索。

## 算法核心思想

- **空间换时间**：通过预处理生成`next`数组，以额外空间代价换取匹配效率的质变。
- **避免重复匹配**：利用已匹配的**前缀信息**，跳过不可能成功的对齐位置，避免无效回溯确保主串仅遍历一次。

### **KMP算法的用途**

KMP算法主要用于**单模式字符串匹配**，其核心优势在于**高效处理大规模文本搜索**，以下是典型应用场景：

### **1. 常见应用场景**

- **文本搜索**
如文本编辑器（VS Code、Sublime等）中的“查找”功能，快速定位关键词。
- **数据清洗**
在日志分析或数据库查询中，快速匹配特定模式（如日期格式、错误代码）。
- **生物信息学**
基因序列比对（如DNA片段匹配），处理长序列时效率显著高于暴力算法。
- **网络安全**
检测网络流量中的恶意特征字符串（如病毒签名、入侵模式）。

### **2. 扩展应用**

- **多模式匹配的基础**
KMP是AC自动机（多模式匹配算法）的预处理优化基础。
- **压缩算法**
如LZ77系列算法中，利用KMP思想快速查找重复子串。

### **实现时的易错点**

KMP算法的实现难点在于**正确构建next数组**和**指针移动逻辑**，以下是常见错误及规避方法：

### **1. 构建next数组的易错点**

- **错误1：初始条件设置错误**
    - **问题**：`next[0]`未初始化为`1`，或指针`j`未从`1`开始。
    - **后果**：后续计算逻辑全盘错误。
    - **规避**：严格遵循初始化规则：
        
        ```python
        next_arr = [-1] * len(pattern)  # next[0] = -1
        j = -1  # 前缀指针初始化为-1
        
        ```
        
- **错误2：未正确处理`j = next[j]`的回退逻辑**
    - **问题**：在`pattern[i] != pattern[j]`时，未循环回退`j`，直接赋值为`next[j]`一次。
    - **后果**：无法找到最长公共前后缀，导致next数组计算错误。
    - **规避**：使用循环条件确保充分回退（代码需内嵌循环或递归逻辑）：
        
        ```python
        while j >= 0 and pattern[i] != pattern[j]:
            j = next_arr[j]
        
        ```
        
- **错误3：索引越界**
    - **问题**：`i`或`j`的递增未检查边界。
    - **后果**：数组越界导致程序崩溃。
    - **规避**：严格限制循环条件（如`i < len(pattern)-1`）。

### **2. 匹配阶段的易错点**

- **错误1：主串指针错误回溯**
    - **问题**：匹配失败时误将主串指针`i`回退（如`i -= j`）。
    - **后果**：时间复杂度退化为O(n*m)，失去KMP优化意义。
    - **规避**：主串指针`i`永不回退，仅模式串指针`j`根据`next`数组调整。
- **错误2：忽略`j == -1`的特殊情况**
    - **问题**：当`j == -1`时未重置`j=0`并移动主串指针`i`。
    - **后果**：陷入死循环（如主串`i`不前进）。
    - **规避**：显式处理`j == -1`：
        
        ```python
        if j == -1:
            i += 1
            j = 0
        
        ```
        
- **错误3：未正确处理匹配完成后的逻辑**
    - **问题**：当`j == len(pattern)`时未及时返回结果，或继续匹配。
    - **后果**：漏报匹配位置或多报重复结果。
    - **规避**：匹配成功后立即记录位置，并重置`j`（若需查找所有匹配）：
        
        ```python
        if j == len(pattern):
            print(f"Match at index {i - j}")
            j = next_arr[j]  # 继续寻找后续可能的匹配
        
        ```

### **验证与调试建议**

1. **测试用例设计**
    - 短模式串（如`"A"`、`"AB"`）。
    - 含重复前缀的串（如`"AAAAA"`、`"ABAB"`）。
    - 完全失配的主串和模式串。
2. **手动计算next数组**
    
    对模式串手动计算`next`数组，与代码输出对比（如模式串`"ABABC"`的`next`应为`[-1, 0, 0, 1, 2]`）。
    
3. **边界条件测试**
    - 模式串与主串长度相等。
    - 模式串长度大于主串。

---

### **总结**

KMP算法通过**空间换时间**的策略优化字符串匹配，但其实现需严格处理`next`数组的构建与指针回退逻辑。**避免主串指针回溯**和**正确处理`j == -1`**是保证效率的关键。通过设计针对性测试用例和手动验证中间结果，可有效规避常见错误。
