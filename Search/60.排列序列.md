## 暴力思路
从第一个位置开始dfs搜索，每一次搜索都有一个数组v存储还剩下的数，for遍历dfs搜索数组里的数,当数组v只剩一个数时返回最后一个数"x"，dfs返回搜索到的当前位置放的数string

string dfs(i){
    在v只有一个元素的时候exit,return最后一个元素"x", 返回后k--;
    v删掉i;
    for t: v剩下的元素
        ans += dfs(t)
}
for i: 在一个位置上遍历1->n
    ans = dfs(i);
    if k == 0 break;
