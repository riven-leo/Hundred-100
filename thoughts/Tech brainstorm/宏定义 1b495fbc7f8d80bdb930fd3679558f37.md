# 宏定义

**什么时候用 `INT_MAX` 和 `INT_MIN`？**

1. **初始化极值**
    
    在需要动态维护最大/最小值时（如数组最值、贪心算法），用它们初始化变量：
    
    ```cpp
    int min_val = INT_MAX; // 初始化为最大可能的整数
    int max_val = INT_MIN; // 初始化为最小可能的整数
    ```
    
2. **防止整数溢出**
    
    在涉及数学运算（如反转整数、累加）时，提前判断是否超出 `int` 范围：
    
    ```cpp
    int reverse(int x) {
        int rev = 0;
        while (x != 0) {
            int pop = x % 10;
            x /= 10;
            // 检查溢出
            if (rev > INT_MAX/10 || (rev == INT_MAX/10 && pop > 7)) return 0;
            if (rev < INT_MIN/10 || (rev == INT_MIN/10 && pop < -8)) return 0;
            rev = rev * 10 + pop;
        }
        return rev;
    }
    ```
    
3. **边界条件处理**
    
    当输入可能包含极值（如题目明确说明数据范围包含 `int` 的极限值时）。
    

**典型应用场景**

- **动态规划**：初始化 DP 数组时用 `INT_MAX` 表示不可达状态。
- **图算法**：用 `INT_MAX` 表示两点之间无直接边（如 Dijkstra 算法）。
- **输入处理**：用 `EOF` 判断输入结束。
- **溢出保护**：任何涉及 `+`、 的运算都可能需要检查 `INT_MAX`/`INT_MIN`。
