**TurtleSoup.java**
基于一个只会“前进、转向”的 Turtle，构造更高层的绘图能力，并把复杂行为拆成可以单独验证的小模块。

Turtle 怎么画正方形？
重复 4 次：
    前进 sideLength
    右转 90°
主要练习：重复结构 + Turtle API。

如果不是 4 条边，而是任意 n 条边怎么办？
边数 -> 内角和: (n-2) x 180
内角和 -> 边数： s/180 +2
如果是正polygon 特殊处理

我现在在 A 点，当前朝某个方向，我要去 B 点，需要向右转多少度？calculateHeadingToPoint()
给我一串坐标，我应该依次转多少度，才能从第一个点走到最后一个点？calculateHeadings()

Decomposition structure:
                 整体需求
         “让 Turtle 完成复杂绘图”
                   │
                   ↓
              拆分功能
                   │
        ┌──────────┼───────────┐
        ↓          ↓           ↓
      图形       几何计算      路径计算
        │          │           │
        ↓          ↓           ↓
     function   function     function
                   │
                   ↓
               unit test
