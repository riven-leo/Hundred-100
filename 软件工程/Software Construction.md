**至于你说：“由我自己来古法写代码，在现在这个时代已经没有意义了。”**
    我基本同意一半，而且这一半非常重要。

    如果“自己写代码”指的是：

    for (int i = 0; i < 4; i++) {
        turtle.forward(sideLength);
        turtle.right(90);
    }

    然后花半小时证明“我没看 AI，我完全自己写出来了”。

    这个能力的价值确实已经大幅下降了。

    AI 能在几秒钟生成，而且这段代码本身没有多少值得训练的东西。

    但如果进一步推成：

    “所以我不用理解代码了。”

    那就会走到另一个极端，而且非常危险。

    现在更有价值的能力已经从：

    我能不能从空白编辑器写出这段代码

    逐渐转成：

    AI 给我的代码对不对？
    为什么这么设计？
    有没有违反 specification？
    哪里有隐藏 bug？
    测试够不够？
    需求变化以后怎么改？
    这些代码应该怎么拆？

    刚才你的 drawRegularPolygon 就是一个很好的例子。

    AI 可以写代码。

    但如果它写：

    turtle.right(interiorAngle);

    你必须有能力判断：

    不对，这里 API 要的是 Turtle 的旋转量，所以应该用 exterior angle。

    这才是现在越来越重要的能力。
