### 14. (单选题)以下程序的输出结果是( )。

```c
int main()
{
     int a=53,b=18,c=0;
     if(b<a)
          if(b>10)
          {
               c=a--;
               c++;
          }
     b++;
     printf(“%d,%d,%d”,a,b,c);
     return 0;
}
```

- B. 54,18,52
- C. 52,19,52
- D. 52,18,52

# 第六次作业 指针

### 8. (单选题)若有以下程序段:程序运行后的输出结果是( )。

```cpp
int main()
{
     int x[]={10,20,30};
     int *px=x;
     printf("%d,",++*px);     // 将10加一再输出，输出11
     printf("%d,",*px);       // 输出11
     px=x;                    // 指向x[0]
     printf("%d,",(*px)++);   // 先输出11，将11加一到12
     printf("%d,",*px);       // 输出12
     px=x;                    // 指向x[0]
     printf("%d,",*px++);     // 先输出12，然后px移动到下一个位置
     printf("%d,",*px);       // 输出20
     px=x;                    // 指向x[0]
     printf("%d,",*++px);     // 先指针自增到x[1]，输出20
     printf("%d\n",*px);      // 输出20
     return 0;
}
```

- A. 11,11,11,12,12,20,20,20
- B. 20,10,11,20,11,12,20,20
- C. 20,10,11,10,11,10,11,10
- D. 11,11,11,12,12,13,20,20
