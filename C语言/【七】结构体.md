# 一、字节对齐机制

**规则一：每个成员变量的起始地址必须是其类型大小的整数倍**

```c
struct Example {
    char c;   // 假设 char 占 1 字节，起始地址是 0
    int i;    // 假设 int 占 4 字节，起始地址是 4（而不是 1），以满足 int 的对齐要求
};
```

**规则二：结构体的总大小必须是其最大对齐单位的倍数**

```c
struct Example {
    char c1;   // 1 字节
    char c2;   // 1 字节
    int i;     // 4 字节
};
// 最大对齐单位是 int（4 字节），结构体总大小是 8 字节（而不是 5 字节）
```

空的位置会插入**填充字节（Padding Bytes）**，在上面这个例子中，内存构成就是：

```
| c | c | P | P | i | i | i | i |
```

**更复杂的例子：**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
  struct Date{
    int a,b,c;
  };
  struct Person{
    char name[50];  // 0-49B
    struct Date a;  // 52-63B
    float c;        // 64-67B
    double w;       // 68-75B
  }ps;              // 必须是最大size，即sizeof double，8的倍数
  cout<<sizeof ps<<endl;    // 输出80
}
```

**控制字节对齐的方式**

1. `#pragma pack`

用于调整结构体成员的对齐方式

```c
#pragma pack(2)  // 对齐方式为 2 字节
struct Example {
    char a;
    int b;
};
#pragma pack()    // 恢复默认对齐
```

2. `alignas`（C++11）

精确指定对齐要求

```c
struct alignas(16) Example {
    int a;
    char b;
};
```

# 二、结构体**位域**

```c
#include <stdio.h>
typedef struct 
{
	unsigned int first_visit:1;  // 范围0-1
	unsigned int  come_again:1;  // 范围0-1
	unsigned int  days:3;        // 范围0-7
	unsigned int  fingers:29;    // 范围0-2^29-1
}question;
// 总共34bit，但是结构体大小必须为sizeof unsigned int 整数倍，所以为大小为8byte
question q = {1,1,5,10};
int main(int argc, char const *argv[])
{
    printf("%d\n",q.fingers);  // 输出10
    printf("%ld\n",sizeof q);  // 输出8，一共64bit
    return 0;
}
```
