# 思路
最暴力做法：依次合并k个链表，n长度
TC = 2n+3n+...+kn = (1+k)k/2 *n = O(K^2 *n)
第一次合并2n个节点被访问1次

二分数组，在每一层进行两链表合并
核心：
      merge
     /    \
 merge      merge
 /  \      /   \
L1 L2    L3   L4


二分递归合并，从最开始的数组开始保存，需要找中点进行二分，存l和r

递归出口 —— *在二分到只剩一个链表的时候(l == r)，返回，开始进行合并*
*特殊情况退出，数组空的时候*
通常情况确实不会出现空链表的情况，但是当给的lists就是空的时候，merge就是(lists, 0, -1)，就会溢出出错，所以需要考虑数组空的时候也就是l>r
最后输出两个链表合并后的结果(左闭右闭)
