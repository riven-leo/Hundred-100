BFS和DFS实现上一个用队列一个用栈，就能实现层序搜索和深度优先搜索，本质就是数据结构使用的不同

## 思路
start with empty frontier with initial state
start with empty explored set
Repeat:
    if f is empty return no solution 
    remove one from f
    if goal return solution
    add to set
    expand other neighbor:
        not in f and not in set

## 实现错误
1. 循环每个炸弹时定义cnt=1,但是在进入队列弹出访问炸弹时又cnt++；会导致多算一个炸弹；cnt=0即可
2. 现在的代码没有保证heighbor not in f;会导致重复节点进入q,如例子：0 → 1,0 → 2,1 → 3,2 → 3;把出队的时候才to set，提前到入队时就add to set
