# 双层 DP：把两个相互影响的过程放进同一个状态

## 什么时候想到双层 DP

看到下面的信号时，应考虑把两个位置或两个指标同时写入状态：

- 两个人、两个机器人或两条路径同步推进；
- 当前收益取决于两个位置的组合，而不是各自独立；
- 两个过程可能相遇、重复选择或共享资源；
- 除了最优值，还要统计达到最优值的方案数。

核心判断是：**只记录一个主体的位置，是否足以决定后续答案？** 如果不能，就要把另一个主体或另一维信息也放入状态。

## 从暴力搜索到 DP

先写出暴力递归：

1. 当前状态由哪些变量唯一决定；
2. 每个变量下一步有哪些选择；
3. 所有选择组合后会到达哪些子问题；
4. 不同搜索路径是否会重复到达同一组状态。

以两个机器人为例，单步有 `3*3=9` 种组合，但状态总数只有“行数 × 列数 × 列数”。把每个 `(row,col1,col2)` 的答案保存下来，就是从指数搜索到 DP 的关键。

## 状态设计的两种常见形式

### 双位置状态

`dp[row][col1][col2]` 表示两个主体位于同一层的两个位置时的最优答案。若 `row` 只依赖相邻一层，可滚动成两个二维数组。

### 最优值 + 方案数

`dp[state] = {best,count}`。合并候选状态时遵守：

- 候选更优：同时替换 `best` 和 `count`；
- 候选同样优：保留 `best`，累加 `count`；
- 候选更差：忽略。

这套规则可迁移到最短路计数、最大价值路径计数等题目。

## 确定递推顺序

状态依赖谁，就先计算谁：

- 依赖下一行：从下往上；
- 依赖上一行：从上往下；
- 依赖右方和下方：从右下往左上。

不要先背循环方向，先画出一条转移箭头。

## 初始化与不可达状态

初始化是双层 DP 最容易出错的部分：

- 求最大值且可能有负数：不可达状态用负无穷，不能默认用 0；
- 求最小值：不可达状态通常用正无穷；
- 统计方案数：合法起点的计数通常为 1；
- 障碍或越界状态不能参与转移。

## 空间优化

如果第 `i` 层只依赖第 `i+1` 层，可用 `pre/cur` 滚动数组，把 `O(m*n^2)` 空间降为 `O(n^2)`。优化前先写清每个数组的语义，`swap` 后语义随之交换。

## 通用检查表

1. 状态是否包含了决定未来所需的全部信息？
2. 两个主体相遇时，收益应该算一次还是两次？
3. 合并最优值时，方案数应该覆盖还是累加？
4. 不可达状态是否可能被默认值误当成合法答案？
5. 遍历顺序是否保证依赖状态已经计算？
6. 滚动数组是否需要清空，边界填充值是否安全？
